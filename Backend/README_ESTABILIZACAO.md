# Frontend estabilizado

1. Copie `.env.example` para `.env` se necessário.
2. Use Node 22.22.0 ou superior com as dependências atuais.
3. Execute `npm install` e `npm run dev`.
4. O endereço local padrão da API é:
   `http://localhost/estudio-suzuki-api/public/api`

A ficha do aluno foi refatorada em componentes menores e agora permite encerrar matrícula com data de término.
